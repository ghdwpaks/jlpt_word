핵심 원칙 요약
틀린 채로 두지 말고 바로 넘어가기. → 반복보다 '흐름 유지'가 중요.
정확도보다 반응성. → 맞고 틀린 건 중요하지 않음. '떠오르는 속도'가 핵심.
멈추지 말고 한 사이클 완주. → 도중 중단보다, 느리더라도 한 바퀴 돌리는 게 훨씬 효과적.

1단계 — 청음·시각 루프
| 내용 | 한자 10개 선택 → 음독·훈독 말해보기 |
| 방법 | “정확히 말하려고 하지 말고, 대충 이런 소리였지”로 반응 |
| 목표 | 7개 이상 즉발 반응 → 통과 |
| 팁 | 표 보면서라도 입으로 말하면 OK (기억 재점화가 목적) |

2단계 — 의미핵 리콜
| 내용 | 위 10자 중 5개 골라 → 한자당 ‘이미지 1개’ 떠올리기 |
| 방법 | 예: 火 → 불빛, 花 → 정원, 空 → 하늘
| 목표 | 생각 없이 2초 내에 ‘그림’이 떠오르면 OK |
| 팁 | 연상 안 되면 멈추지 말고 다음으로 넘어가. “흐름 유지”가 우선. |

3단계 — 문장 용례 루프
| 내용 | td에서 1자당 문장 1개 → 총 5문장만 |
| 방법 | ① 듣기 → ② 따라 말하기 → ③ 뜻 떠올리기 (3단계 순환) |
| 목표 | 문장 전체 느낌이 “아, 이런 말이구나” 수준이면 통과 |
| 팁 | 정확히 이해 안 돼도 돼. “뇌가 익숙해진다”가 핵심. |

4단계 — 의미망 감각
| 내용 | 단자 3개 묶기 → 공통 이미지 1개 찾기 |
| 예시 | 火・光・熱 → “따뜻한 것” / 金・貝・円 → “가치” |
| 목표 | 3세트 이상 연결 성공 → 통과 |
| 팁 | 말이 안 돼도 돼. ‘감각적으로 묶였다’면 성공. |

5단계 — 정리·재점화
| 내용 | 오늘 말한 한자 중 기억 덜 나는 3개만 재확인 |
| 방법 | 한자 보고 → 발음/뜻 동시에 떠올리기 (최대 3회) |
| 목표 | 마지막에 “익숙하다”는 느낌이 들면 종료 |
| 팁 | 틀린 걸 고치지 말고 “흐름만 다시 연결”하는 느낌으로. |
